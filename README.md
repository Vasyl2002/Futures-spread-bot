# SpreadDesk — крипто спред-терминал (фьючерсы + спот)

Веб-приложение для мониторинга и торговли межбиржевыми спредами: карточки пар,
живые спреды и funding, сигналы в Telegram с рекомендациями, вход в сделку
двумя ногами прямо из браузера и закрытие обеих позиций одной кнопкой.

## Биржи

| Биржа   | Спот | Фьючерсы (USDT-M) |
|---------|------|-------------------|
| Binance | ✅   | ✅                |
| Bitget  | ✅   | ✅                |
| KuCoin  | ✅   | ✅                |
| Gate.io | ✅   | ✅                |

Добавление новых бирж — одна строка в `backend/app/exchange_manager.py`
(любая биржа из [ccxt](https://github.com/ccxt/ccxt)).

## Возможности

- **Карточки пар** как в спред-терминалах: две ноги (биржа + тип рынка),
  направление LONG/SHORT с авто-переключением, пороги входа/выхода, размер,
  плечо, лимит позиций, Start/Stop/Copy, избранное и архив.
- **Мониторинг спредов** во всех комбинациях: фьюч↔фьюч (приоритет), фьюч↔спот,
  спот↔спот. Спред считается по реальному стакану (bid/ask), а не по last price.
- **Funding**: ставка и обратный отсчёт до следующей выплаты по каждой ноге.
- **Telegram-сигналы**: спред, цены ног, funding и рекомендация — чем заходить
  (монетой или USDT) и с каким плечом. Плюс уведомления об открытии/закрытии позиций.
- **Торговля из веб-приложения**: кнопка «Войти в сделку» открывает обе ноги
  одновременно (маркет-ордера), кнопка «Закрыть обе позы» закрывает обе биржи
  одной операцией. Если одна нога не исполнилась — вторая закрывается автоматически.
- **Paper-режим** (по умолчанию): виртуальные сделки по реальным ценам —
  можно тестировать стратегию без API-ключей и риска.
- **Авто-торговля** (опция на карточке): авто-вход при спреде ≥ порога и
  авто-выход при схлопывании до порога выхода.
- **История сделок**: спред входа/выхода, PnL, комиссии, время в сделке, winrate.
- **Графики**: история спреда с линиями порогов + свечные графики монеты с любой ноги.
- **Балансы** спота и фьючерсов по всем биржам (при наличии ключей).

## Обход IP-ограничений

Если биржа блокирует ваш IP для торговли фьючерсами (например, Binance отвечает
ошибкой 451), в «Настройки → биржа → Прокси» укажите прокси **той страны, где
торговля разрешена**:

```
http://user:pass@host:port
socks5://host:port
```

Прокси задаётся отдельно для каждой биржи — весь трафик к этой бирже (публичный
и приватный) пойдёт через него. Остальные биржи продолжают работать напрямую.

## Запуск

```bash
# 1. Бэкенд
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 2. Фронтенд (собирается один раз, отдаётся бэкендом)
cd ../frontend
npm install
npm run build

# 3. Старт
cd ../backend
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000 в любом браузере. Или просто: `./run.sh`.

Для разработки фронтенда: `cd frontend && npm run dev` (проксирует API на :8000).

## Настройка

1. **Настройки → Telegram**: token бота (создать у [@BotFather](https://t.me/BotFather))
   и chat ID ([@userinfobot](https://t.me/userinfobot)), кнопка «Отправить тест».
2. **Настройки → API-ключи**: нужны только для торговли и балансов;
   мониторинг спредов и сигналы работают без ключей.
3. Создайте карточку: монета, две ноги (биржа + спот/фьюч), порог входа в %,
   размер ноги в USDT — и нажмите **Start**.
4. Когда стратегия проверена в paper-режиме — переключите «Режим торговли» на LIVE.

## Архитектура

```
backend/   FastAPI + ccxt (async) + SQLite
  app/exchange_manager.py  — клиенты бирж, стаканы, funding, ордера, прокси
  app/spread_engine.py     — цикл мониторинга, сигналы, авто-торговля, WebSocket
  app/trader.py            — одновременное открытие/закрытие двух ног
  app/telegram_bot.py      — сигналы и рекомендации (маржа, плечо)
frontend/  React + Vite + Tailwind + lightweight-charts
```

⚠️ **Дисклеймер**: торговля криптовалютой с плечом сопряжена с риском полной
потери средств. Проверяйте стратегию в paper-режиме. Это ПО предоставляется
«как есть», автор не несёт ответственности за убытки.
