# SpreadDesk — крипто спред-терминал (фьючерсы + спот)

Веб-приложение для мониторинга и торговли межбиржевыми спредами. Работает в любом браузере.

**Биржи:** Binance, Bitget, KuCoin, Gate.io (спот и USDT-M фьючерсы). Список легко расширяется.

## Возможности

- **Монитор спредов (главное)** — сканер сам смотрит все USDT-пары на 4 биржах
  (фьюч↔фьюч приоритет, плюс фьюч↔спот). Карточки создавать не нужно.
- **Telegram-коллы**: как только спред выше порога — сразу сообщение: монета, лонг/шорт,
  цены, funding, чем заходить (монетой или USDT) и с каким плечом. Карточку открываешь
  потом, если сам хочешь зайти.
- **Карточки пар** — для ручного наблюдения и торговли конкретной пары после колла.
- **Торговля из веба**: кнопка «Войти в сделку» открывает обе ноги одновременно,
  «Закрыть обе позы» — закрывает обе ноги одной кнопкой. Позиции подсвечиваются на карточках
  с PnL по каждой ноге и суммарным.
- **Paper-режим** (по умолчанию): сделки симулируются по реальным ценам стакана — можно
  тестировать без API-ключей и риска. Live-режим отправляет реальные маркет-ордера.
- **Авто-режим** per-карточка: авто-вход при достижении порога и авто-выход при схлопывании.
- **График**: спред карточки в реальном времени + свечной график монеты с любой ноги.
- **История сделок**: спред входа/выхода, PnL, комиссии, длительность, winrate.
- **Аккаунт**: балансы спота и фьючерсов всех бирж.
- **Обход IP-ограничений**: на каждую биржу можно назначить свой прокси
  (`http://user:pass@host:port` или `socks5://host:port`) — так торговля фьючерсами Binance
  работает даже если сервер стоит в запрещённом регионе.

## Быстрая установка на VPS (Ubuntu)

```bash
git clone https://github.com/Vasyl2002/Futures-spread-bot.git
cd Futures-spread-bot
sudo bash deploy/install.sh
```

Скрипт сам создаст swap, установит зависимости, соберёт фронтенд, спросит пароль для
веб-интерфейса и настроит автозапуск через systemd (работает 24/7, переживает перезагрузку).
После установки открывайте `http://<IP сервера>:8000`.

Пароль хранится в переменной окружения `SPREADDESK_PASSWORD` (см.
`/etc/systemd/system/spreaddesk.service`). Без этой переменной приложение запускается без
авторизации — допустимо только локально.

## Запуск вручную

### Backend (Python 3.11+)

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Frontend (Node 18+)

```bash
cd frontend
npm install
npm run build        # прод-сборка — backend сам отдаёт frontend/dist
# или для разработки:
npm run dev          # http://localhost:5173 (проксирует API на :8000)
```

После сборки фронтенда открывайте **http://localhost:8000** — это и есть веб-приложение.

## Настройка

1. **Настройки → Биржи**: вставьте API-ключи (для KuCoin и Bitget — ещё passphrase).
   Ключам достаточно прав «чтение + торговля», вывод средств не нужен.
2. **Прокси** (если биржа блокирует ваш IP): укажите прокси в поле соответствующей биржи.
3. **Telegram**: создайте бота у [@BotFather](https://t.me/BotFather), получите свой chat id
   у [@userinfobot](https://t.me/userinfobot), вставьте оба значения и нажмите «Отправить тест».
4. Создайте карточку: монета, две ноги, порог спреда — и нажмите **Start**.

## Как читать сигнал в Telegram

```
🔔 СИГНАЛ: BTC/USDT
Спред: +0.62% (порог 0.4%)
🟢 LONG GATE.IO (фьюч) по ~63681
🔴 SHORT BITGET (фьюч) по ~64077
Funding: long +0.0100% | short −0.0056% (edge +0.0156%/8ч)
💡 Рекомендация:
• Заход: USDT (USDT-M): funding работает в вашу пользу
• Плечо: 4x
```

Плечо рассчитывается от величины спреда (больше спред — больше допустимое плечо, максимум 10x),
рекомендация «монетой или USDT» — от типа ног и направления funding.

## Архитектура

- `backend/` — FastAPI + ccxt (async): движок опрашивает стаканы обеих ног каждые 2 с,
  считает спреды в обе стороны, funding, PnL открытых позиций и транслирует всё на фронт
  по WebSocket. SQLite хранит карточки, позиции, историю и настройки.
- `frontend/` — React + TypeScript + Tailwind + lightweight-charts.

## Безопасность

- Ключи хранятся только в вашей локальной SQLite-базе (`backend/spreaddesk.db`), в API
  отдаются замаскированными.
- Live-ордера используют reduce-only при закрытии фьючерсных ног; при частичном исполнении
  входа выполняется аварийное закрытие исполнившейся ноги, чтобы не остаться с голой позицией.
